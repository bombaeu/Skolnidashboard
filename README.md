# 🎓 Školní Dashboard

Přehledný webový dashboard pro studenty – jedno místo, kde má student pohromadě rozvrh, úkoly a důležité informace ke studiu. Důraz je kladen na čistý, moderní vzhled a snadnou orientaci. Jde o frontendový projekt postavený na čistém HTML, CSS a JavaScriptu, s podporou více vzhledů (témat) a vlastních widgetů.

## ✨ Funkce

**Přehled rozvrhu** a školních povinností na jednom místě. **Widgety** jako modulární prvky dashboardu (složka widgets/). **Témata vzhledu** s přepínáním mezi styly (složka themes/). **Světlý a tmavý režim** a **responzivní design** pro mobil i počítač.

## 🛠️ Použité technologie

HTML5, CSS3 a JavaScript. Projekt nepoužívá žádný build ani externí závislosti.

## 🚀 Spuštění

Projekt stačí naklonovat a otevřít index.html v prohlížeči (ideálně přes rozšíření Live Server ve VS Code).

```bash
git clone https://github.com/bombaeu/Skolnidashboard.git
cd Skolnidashboard
```

## 📂 Struktura projektu

```
Skolnidashboard/
  index.html     hlavní stránka dashboardu
  style.css      styly
  widgets/       jednotlivé widgety
  themes/        vzhledy a barevná témata
  fotky/         obrázky a ikony
  docs/          dokumentace
```

## 🧭 Co bych chtěl dodělat

Ukládání nastavení uživatele (localStorage), napojení na reálná data místo statických a více widgetů (počasí, známky, kalendář).
